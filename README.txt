이우연 링크 사이트 (Cloudflare Pages 배포용)

이 폴더를 통째로 Cloudflare Pages에 올리면 됩니다.
Workers & Pages > 만들기 > Pages > 에셋 업로드(Upload assets) > 폴더 끌어다 놓기 > 배포

수정할 곳
- 링크와 문구: index.html
- 책 출간 후: app.js 맨 위 BOOK_OUT = false 를 true 로
- 색과 서체: style.css

폰트 안내: Pretendard(OFL), 머니그라피(토스 제공, 웹 임베딩 허용·폰트 파일 단독 재배포 금지)
